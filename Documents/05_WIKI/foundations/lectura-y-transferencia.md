# Lectura situada y transferencia creativa

## Una ficha por problema, no un resumen por autor

| Registro | Contenido mínimo |
|---|---|
| Fuente | URL original o documento, sección consultada, fecha y alcance de lectura. |
| Problema construido | Entidades, relaciones, medición, explicación y criterio de éxito. |
| Afirmación de la fuente | Resultado y condiciones; distinguir demostración, experimento y propuesta. |
| Interpretación propia | Modelo relacional reconstruido y grado de incertidumbre de esa lectura. |
| Ausencias | Qué queda fuera; posibles causas abiertas, sin atribuir intención. |
| Uso original | Operación para la que se desarrolló la herramienta. |
| Reutilización propuesta | Nueva pregunta u operación, aunque sea ajena al propósito original. |
| Traducción | Correspondencias, supuestos conservados/cambiados y garantías perdidas. |
| Contraste | Control fuerte y observación que debilitaría la propuesta. |
| Condiciones materiales | Implementación, licencia, coste, datos permitidos y accesibilidad. |
| Próxima incertidumbre | Qué consultar o experimentar después y por qué. |

## Tres estatutos que no se mezclan

1. **La fuente sostiene:** afirmación verificable en el original.
2. **Interpretamos:** reconstrucción situada, discutible y trazable.
3. **Proponemos:** invención propia cuyo valor aún debe examinarse.

Un silencio puede responder al alcance, costes, disponibilidad de datos, tradición o límites conceptuales. No permite elegir una explicación sin evidencia. Entender el discurso como construcción situada no lo convierte en ficción ni elimina la fuerza de una prueba bajo sus supuestos.

## Ejemplo de traslado a CASMI — propuesta, no resultado

Una herramienta de satisfacción de restricciones podría servir para comprobar consistencia química de candidatos, aunque provenga de otro campo. El traslado exige especificar variables químicas, restricciones justificadas, tolerancias de medición y qué incertidumbre permanece. Un candidato que satisface restricciones no queda identificado como la molécula verdadera; también puede ocurrir que una restricción mal trasladada descarte la respuesta correcta.

La pregunta no es sólo si el software puede ejecutar el cálculo: es qué significa ese cálculo para esta medición y qué evidencia permite decidir si ayuda.

## Política de wiki

Síntesis relacionales, tensiones, enlaces y preguntas; no duplicación del contenido de papers. Volver al original cuando una decisión dependa de él. Informes crudos separados de síntesis en Biblioteca; evitar secretos y registros de datos restringidos. Ningún consenso entre agentes sustituye una validación empírica o revisión experta pertinente.
