# Style Profiles

## Tier A (design reinforced)

Apply reinforced formatting and navigation only to:
- `README.md`
- `Documents/INDICE_DOCUMENTACION.md`
- `Documents/Proyecto_Estado_Actual.md`
- `Documents/BIAS_CONTROL/ROADMAP_BIAS_CONTROL.md`

Guidelines:
- Keep a clear top summary and fast navigation section.
- Keep status/date fields explicit.
- Keep tables readable and decision-oriented.
- Avoid verbosity without losing context.

## Tier B (sober operational docs)

Apply to all other docs.

Guidelines:
- Prioritize short factual updates.
- Keep sections: what changed, why, evidence, next step.
- Use simple formatting and moderate length.

## Always enforce

- Respect collab mode (`OFF` by default).
- Do not edit `PENDIENTES.md`.
- Do not edit `CLAUDE.md`.
- Keep consistency with `CODEX.md`.
