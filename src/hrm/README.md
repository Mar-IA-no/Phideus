# Hierarchical Reasoning Model (HRM) Implementation

Implementation of the Hierarchical Reasoning Model architecture for harmonic structure analysis in Phideus v4.1, based on the scientific paper by Sapient Intelligence.

## 🏗️ Architecture Overview

The HRM implements a dual-timescale neural architecture with:

- **H-Module**: High-level reasoning with slow timescale updates (every N cycles)
- **L-Module**: Fast spectral computation with high temporal resolution
- **Hierarchical Convergence**: Core mechanism with O(1) memory complexity
- **Adaptive Computation Time (ACT)**: Q-learning based dynamic activation

### Key Innovations

1. **O(1) Memory Complexity**: Unlike standard RNNs with O(T) memory growth, HRM maintains constant memory usage through periodic state resets
2. **Deep Supervision**: Multiple forward passes with gradient detachment for stable training
3. **Dual Timescales**: L-Module operates at fast timescale, H-Module at slow timescale for hierarchical reasoning
4. **ACT Integration**: Dynamic halting decisions based on harmonic complexity analysis

## ⚙️ Configuration Options

### Model Architecture

- `l_hidden_dim`: L-Module hidden dimension (default: 256)
- `h_hidden_dim`: H-Module hidden dimension (default: 128)
- `N`: Number of high-level cycles (default: 4)
- `T`: Number of low-level steps per cycle (default: 8)
- `convergence_type`: Type of convergence mechanism
  - `standard`: Basic hierarchical convergence
  - `adaptive`: Adaptive N/T based on complexity
  - `residual`: With residual connections
- `act_type`: Type of ACT mechanism
  - `standard`: Basic Q-learning ACT
  - `enhanced`: Enhanced with harmonic analysis

### Training Parameters

- `batch_size`: Training batch size (default: 16)
- `learning_rate`: AdamW learning rate (default: 1e-4)
- `epochs`: Number of training epochs (default: 100)
- `mixed_precision`: Use FP16 training (auto-enabled on GPU)
- `gradient_clip_norm`: Gradient clipping threshold (default: 1.0)

### Mathematical Framework

The HRM implements the following key equations:

**Hierarchical Convergence:**
```
L_t^(i) = L-Module(x_t, H_{cycle}, L_{t-1}^(i))
H_{cycle+1} = H-Module(L_T^(N), H_{cycle})
```

**Deep Supervision:**
```
Loss = α₁L_recon + α₂L_conv + α₃L_act + α₄L_deep
```

**ACT Decision:**
```
Q(s_t, a) = Q-Network(L_t)
halt_t = argmax_a Q(s_t, a) with ε-greedy exploration
```

## 🚨 Troubleshooting

### Common Issues

1. **CUDA out of memory**: Reduce batch size or use smaller model dimensions
2. **NaN losses**: Ensure proper gradient clipping and learning rate
3. **Slow convergence**: Try adaptive convergence type or adjust N/T parameters
4. **Dataset loading errors**: Verify JSON format matches expected schema
